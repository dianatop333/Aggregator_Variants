#Агрегатор вариантов
Консольная программа для выбора и запуска программ
## Назначение
Предоставление пользователю меню для выбора доступных программ.

## Теxнологии разработки
- Язык программирования: Python
- Система контроля версий: Git
- Удаленный репозиторий : GitHub
- Среда разработки : Visual Studio Code
## Статус проекта
Разработка проекта находится на начальном этапе.
